## Contexto do Projeto

Foi proposto pela empresa parceira Altave o desenvolvimento de uma plataforma semelhante a um **LinkedIn interno**, voltada para o cadastro e gerenciamento de talentos e competências dos colaboradores.

O objetivo principal era centralizar informações profissionais dos funcionários, facilitar a busca por perfis específicos e apoiar processos de identificação de talentos e realocação interna dentro da organização.

---

## Solução Desenvolvida

A equipe desenvolveu uma aplicação web com foco no backend para gerenciar perfis profissionais, competências, áreas de atuação e hierarquia de usuários. A solução permitiu:

* cadastro de perfis profissionais;
* registro de competências e experiências;
* organização por nível hierárquico de usuários;
* visualização de talentos por área ou equipe;
* busca estratégica de colaboradores;
* gestão de dados para realocação interna;
* geração de relatórios de competências por setor.

O backend foi estruturado para atender às regras de negócio da aplicação, garantindo organização dos dados, consistência das relações entre usuários e suporte às consultas gerenciais.

## Tecnologias Utilizadas

> - **Java**: linguagem principal utilizada no desenvolvimento do backend.
> - **Spring Boot**: framework utilizado para construção da API e regras de negócio.
> - **Angular**: frontend utilizado para interface da aplicação.
> - **MySQL**: banco de dados para armazenamento e persistência das informações.
> - **Flyway**: versionamento e gerenciamento das migrations do banco de dados.
> - **Git e GitHub**: versionamento e colaboração entre os membros da equipe.
> - **Swagger**: documentação e testes dos endpoints da API.
